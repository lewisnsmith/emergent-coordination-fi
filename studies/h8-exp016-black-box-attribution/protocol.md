# H8 black-box input attribution

## Question

Which supplied facts causally alter investment decisions from sampled closed-model endpoints?

## Design

Within observation-prompt-model blocks, apply feature masks, value replacements, order changes, and
salience perturbations while holding non-target content fixed. Sham masks, negative-control facts,
and semantically neutral rewrites calibrate the intervention pipeline. Every resolved provider and
prompt payload is hash-bound with authorization and cumulative cost provenance.

## Estimands, units, and controls

Estimate paired decision change by frozen feature family. The independent unit is an
observation-prompt-model intervention block; retries and response seeds are nested. Freeze
one-factor integrity, missing/invalid outcomes, Holm correction, shams, negative controls, and
semantic-equivalence review before execution.

## Failure rules and limits

Provider drift, unauthorized calls, cost-ledger gaps, multiple changed factors, failed semantic
controls, or incomplete blocks prevents the affected claim. Closed-model interventions support
black-box causal input attribution only. Rationales are not mechanism evidence, and exp-016 does
not establish an H12 pressure effect.

## Execution sequence

1. Freeze the intervention grammar, outcomes, blocks, controls, and multiplicity.
2. Implement fail-closed authorization, provider provenance, and cumulative cost accounting.
3. Verify one-factor transformations and controls without paid execution.
4. Gate provider calls, spending, and output-release rights.
5. Run the frozen paired blocks and preserve every invalid or failed response.
6. Release all verdicts with black-box-only labels and intervention-integrity evidence.
